# 🛍️ E-commerce Frontend

A modern, responsive, and user-friendly e-commerce web application built with **Next.js 14 (App Router)**, **TypeScript**, and **Tailwind CSS**.

## 🚀 Features

- ✅ Product listing with image carousel
- ✅ Product detail page
- ✅ Responsive design (mobile-friendly)
- ✅ Optimized with Next.js Image component
- ✅ Clean UI with Tailwind CSS
- ✅ React Icons integration

## 🛠️ Tech Stack

| Tech             | Description                             |
|------------------|-----------------------------------------|
| **Next.js**      | React framework for production          |
| **TypeScript**   | Type-safe JavaScript                   |
| **Tailwind CSS** | Utility-first CSS framework             |
| **React Icons**  | Icon pack for React applications        |
